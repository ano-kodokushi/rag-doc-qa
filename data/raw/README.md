# 语料目录（data/raw/）

把待检索的原始文档放进本目录，然后运行入库命令切块写向量库：

```powershell
$P = "C:\Users\a2695\AppData\Local\Programs\Python\Python312\python.exe"
$R = "C:\Users\a2695\Desktop\作业\Agent\rag-doc-qa"
Set-Location $R
& $P -m src.ingest
```

## 支持的格式

| 扩展名 | 说明 |
| --- | --- |
| `.md` | 优先推荐：结构清晰、切块效果好（按标题层级切） |
| `.txt` | 纯文本，注意用 UTF-8 编码保存 |
| `.pdf` | 由 `pypdf` 抽取文本；扫描件/图片型 PDF 抽不出文字，**不要放** |

编码统一 UTF-8。文件名建议加两位数字前缀（`01_`、`02_`…）以便控制顺序，
例如 `00_保洁系统_项目说明.md`。

## 版权注意（重要）

- **不要提交第三方版权文档。** 框架/数据库官方文档只供本地离线检索学习，
  下载后放在本目录即可，本目录内容默认被 `.gitignore` 忽略（只放行本说明文件）。
- 不要把公司的内部文档、含个人信息或密钥的文档放进公开仓库。
- 语料里的表格、图片说明等非正文内容可能抽取不完整，请人工抽查切块结果
  （`data/chunks.jsonl`）后再出评测题。
- 本目录只放文档；切块结果 `data/chunks.jsonl` 与向量库 `data/chroma/` 均为生成物，不入库。
